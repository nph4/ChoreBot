# Purpose
    ChoreBot is a vibe-coded webapp that serves multiple purposes: To learn AI skills, and to clean my messy house.

    The goal is to generate SMART (Specific, Measurable, Assignable, Realistic, Time-bound) chores to help me keep my house tidy.

# Architecture:
     The application will live in a docker container, be django-based, and store it's data in a PostgreSQL DB.
